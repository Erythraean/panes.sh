Simple ANSI color palette demonstration.
Originally written by GekkoP, adapted for posix compliance.

usage:
chmod +x panes 
./panes

installation: 
(run as root for the default /usr/local prefix, or use a custom PREFIX.)
chmod +x install.sh
./install.sh

compatibility:
Original used \e, which i swapped to \033 for compatibility.
